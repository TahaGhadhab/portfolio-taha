# Portfolio de Taha Ghadhab — Synthèse du concept

## 1. Profil

**Taha Ghadhab** — Ingénieur en génie industriel

- Cursus ingénieur à l'École Nationale d'Ingénieurs de Bizerte (ENIB), diplôme 2024–présent
- Master en Systèmes Complexes Intelligents à l'École Polytechnique de Tunis (en cours)
- Stages : Safran (ingénieur méthode — aéronautique), SMIP (assistant ingénieur — pétrolier), AFC (apprenti consultant — finance)
- Co-fondateur de **PharmacoWork** (outil de gestion RH pour pharmacies)
- Président du club AI Innovators ENIB
- Passions : IA appliquée, informatique, finance, entrepreneuriat, Industrie 4.0

**Méthode de travail (fil rouge du portfolio)**
1. Identifier un problème ou un point d'amélioration
2. Concevoir un système intelligent pour le résoudre
3. Implémenter le changement de la meilleure façon possible
4. Mesurer le gain : temps gagné, qualité montée

**Phrase signature à garder telle quelle :**
> "Je ne fais pas que corriger des problèmes, je les élimine définitivement avec des outils innovants."

**Positionnement unique** : triple casquette rare — rigueur d'ingénieur industriel + appétence data/IA + sensibilité business/finance/entrepreneuriat. Le portfolio doit rendre cette combinaison évidente, pas juste énumérer des compétences séparées.

## 2. Objectif du site

- **Cible prioritaire** : recruteurs en ingénierie / tech / industrie
- **Cible secondaire** : investisseurs et partenaires potentiels (contexte PharmacoWork)
- **Personnalité voulue** : technique, précise, esprit ingénieur/aéronautique
- **Ton général** : sérieux mais habité — pas un CV plat, mais pas non plus un gadget qui prend le pas sur le contenu

---

## 3. Concept créatif retenu : "Salle de contrôle"

Le visiteur ne visite pas un site, il **prend les commandes** d'un centre de pilotage industriel — cohérent avec le fait que Taha ne subit pas les problèmes, il les pilote.

### Métaphores combinées
- **Cockpit / tableau de bord** : instruments, jauges, HUD, interrupteurs — pour la navigation et les compétences
- **Chaîne de montage** : flux linéaire de stations — pour les expériences professionnelles

### Arc narratif
Progression du "concret" vers la "vue d'ensemble" :
`Usine / terrain (stages)` → `Chaîne de montage (méthode)` → `Tour de contrôle (vision, PharmacoWork, master systèmes complexes)`

Cet arc reflète la trajectoire réelle de Taha : de l'exécution terrain vers le pilotage stratégique.

### Séquence d'ouverture
- Écran qui "boot" façon système embarqué : lignes de diagnostic (`SYSTEM CHECK... OK`, `LOADING PROFILE: TAHA GHADHAB`)
- **Durée : 1 à 2 secondes maximum, skippable au clic** (correction post-critique)
- Nom affiché comme un readout HUD, pas un titre statique
- Compteur d'ouverture avec des chiffres clés : ex. `3 stages / 1 startup / 42 KPI trackés`
- Baseline affichée : la phrase signature de Taha

### Section Expériences — la chaîne de montage
- Flux horizontal avec une station par expérience (Safran, SMIP, AFC)
- Chaque station montre une entrée "problème identifié" (visuel cassé/rouge) et une sortie "outil livré" (visuel propre/vert)
- Au survol : mission, outil développé (ex. OCR local chez Safran), résultat obtenu

### Section Projets — mur d'écrans de contrôle
- Plusieurs "moniteurs" façon salle de surveillance : PharmacoWork, Machine Layout Optimization App, Dashboard de Performance Académique ENIB
- Clic sur un écran → passage en plein cadre avec le détail du projet

### Section Compétences — instruments de cockpit
- Cadrans analogiques avec aiguilles animées plutôt que des barres de progression classiques
- Regroupement par domaine : Lean/Industrie (DMAIC, PDCA, VSM), Data (SQL, Power BI, Python), Dev (React, Supabase, MATLAB, CATIA V5)

### Easter egg
- Un voyant d'alerte discret sur le tableau de bord qui, cliqué, révèle un aspect plus personnel (sport/musculation, anecdote, passion) — humanise sans casser la cohérence

## 4. Corrections et garde-fous (validés)

Points de vigilance identifiés et solutions retenues :

| Risque | Solution retenue |
|---|---|
| La forme prend le pas sur le fond (gadget) | Réserver la métaphore cockpit/usine aux sections où elle est pertinente (expériences, projets) ; rester sobre pour "à propos" / "contact" |
| Info clé noyée dans l'animation | **Mode double** : bouton "Vue classique" toujours visible en plus de l'expérience immersive |
| Recruteur pressé / ATS ne trouve pas l'essentiel | **CV PDF téléchargeable en un clic**, toujours visible |
| Charge de développement trop lourde | Prioriser un socle solide et lisible avant d'ajouter les couches d'animation avancées |
| Boot trop long | Boot limité à 1-2 secondes, skippable |
| Mobile illisible avec trop de widgets HUD | **Mobile-first** : garder l'esprit visuel, simplifier drastiquement l'interactivité sur petit écran |
| Sur-thématisation forcée (ex. "leadership" dans une jauge) | Ne pas forcer chaque compétence molle dans la métaphore ; garder ces sections plus classiques |

### Principes de design retenus suite à la critique
1. **Mode double obligatoire** : expérience immersive + vue classique/texte scannable
2. **Mobile-first** avant desktop-first
3. **CV PDF toujours accessible**, dès la landing
4. **Boot court et skippable**
5. **Métaphore appliquée sélectivement**, jamais forcée

## 5. Structure du site (proposition)

1. **Landing / Cockpit** — boot court, nom en HUD, baseline, compteur clé, accès CV PDF, bouton vue classique
2. **Parcours** — formation (ENIB, Polytechnique Tunis, prépa FST) présentée simplement, chronologie claire
3. **Expériences** — chaîne de montage (Safran, SMIP, AFC)
4. **Projets** — mur d'écrans (PharmacoWork, Machine Layout App, Dashboard ENIB)
5. **Compétences** — cadrans cockpit par domaine
6. **Vie associative** — club AI Innovators (président puis responsable RH)
7. **Contact** — sobre, direct, avec liens (email, LinkedIn, téléphone) + CV PDF
